# Task 2: Command Line Practice

1. mkdir: Creates new directories.
2. touch: Creates empty files.
3. cp: Copies files.
4. mv: Moves or renames files.
5. rm: Deletes files.
6. ls: Lists files and directories.
7. cat: Displays file contents.
8. wc -l: Counts lines in a file.

### Difference between > and >>

> replaces the existing content with new content.
>> adds new content at the end of the file.

### File Permissions

I observed that files have permissions such as -rw-------. These show who can read, write, or execute a file.
